## 📘 Folder Details

*   **Course-Modules/**: This is the main folder for my guided learning. It contains all the topics, assignments, and projects taught in the Ostad course. 
*   **Personal-Roadmap/**: This folder is dedicated to topics outside the standard course curriculum that I am exploring on my own to level up as a backend engineer (e.g., advanced database queries, system design concepts, custom APIs).

Inside every module, the files are organized topic-wise. Each topic may include:
*   **Class Code / Scripts:** Python scripts or Django apps written during classes or self-study.
*   **Practice Projects:** Mini-projects and API endpoints built to strengthen backend concepts.
*   **Resources:** Documentation links, database schemas, Postman collections, and personal notes.
